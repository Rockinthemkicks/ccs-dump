# CCS Node Dump
Diagnostic Android app. Built by GitHub Actions (see .github/workflows/build.yml).
Download the APK from the repo's Releases page (latest "Build N").

Use: turn on "Use CCS Node Dump" in Accessibility settings, then open MobileCCS.
Each screen is saved ~3 s after it loads (phone buzzes). Dumps go to Downloads/ccs-dumps/.
